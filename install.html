Installation

Get AI4BayesCode running.

Two ways to use it. Drive it from an AI coding assistant (install it as a skill, then describe your model in plain English), or install the R / Python package and call it from code. Pick one:

The repository root is the skill package. Install it once for your assistant, reload, then type the slash command and describe your model.

Claude Code
# clone, then copy in (re-running overwrites any existing install)
git clone https://github.com/zjg540066169/AI4BayesCode.git
cd AI4BayesCode
mkdir -p ~/.claude/skills
rsync -a --delete --exclude '.git/' ./ ~/.claude/skills/AI4BayesCode/

Reload Claude Code, then type /AI4BayesCode.

Codex
# clone, then copy in (re-running overwrites any existing install)
git clone https://github.com/zjg540066169/AI4BayesCode.git
cd AI4BayesCode
mkdir -p ~/.codex/skills
rsync -a --delete --exclude '.git/' ./ ~/.codex/skills/AI4BayesCode/

Restart Codex, then type /Ai4bayescode (Codex lowercases the skill name, so only the first letter is capitalized).

Other LLM
# paste this to any AI coding assistant
Please install AI4BayesCode by following
this guide, without overwriting files
without backup:
https://github.com/zjg540066169/AI4BayesCode/blob/main/AI_AGENT_INSTALL.md

Your assistant reads the guide and installs the skill itself.

After install — type the slash command. It first asks what you want to do: generate a sampler (compose existing blocks for your model) or design a new block (build a new sampling primitive). Choose generate a sampler, then describe your model in plain typeable text (spell Greek out: beta, sigma): 

# Claude Code: /AI4BayesCode    ·    Codex: /Ai4bayescode
# then choose "generate a sampler", and describe the model:
y ~ N(Xbeta, sigma^2) with Jeffreys prior p(sigma^2) propto 1/sigma^2

The block-design flow is the other path — for building a new sampling primitive when no existing block fits. Pure-C++ users need only a C++17 compiler; the bundled include/ headers are the install.

The same library ships as installable R and Python packages — self-contained (C++ headers + skill corpus travel inside). Describe the model in plain text and generate() writes and validates the sampler.

R
# needs a C++17 compiler + Rcpp, RcppArmadillo
remotes::install_github(
  "zjg540066169/AI4BayesCode", subdir = "r-pkg")

library(AI4BayesCode)
ai4bayescode_generate(
  "y ~ N(Xbeta, sigma^2) with Jeffreys prior")
Python
# Python >= 3.11; a C++ compiler; brew install armadillo
pip install "git+https://github.com/zjg540066169/AI4BayesCode.git#subdirectory=python"

# then, in Python:
import AI4BayesCode
AI4BayesCode.generate(
    "y ~ N(Xbeta, sigma^2) with Jeffreys prior")

generate() uses an LLM (Claude or OpenAI) to write the sampler; pass your key with API_key= or set it once with set_key(). Or run a built-in: ai4bayescode_example("GaussianLocationScale").
