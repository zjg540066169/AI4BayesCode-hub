Tutorial

Tutorial.

A step-by-step walk-through of generating a sampler from a plain-language model, and of designing your own block. Full guide coming soon

What it will cover

  1. Install AI4BayesCode for your coding agent, or as an R or Python package. See the Install page.
  2. Describe your model in plain language, with its likelihood and priors.
  3. Answer the setup questions and confirm the parsed model before any code is written.
  4. Get a validated sampler and run it, with R-hat, ESS, and diagnostic plots attached to every chain.
  5. Design and share a new block when no built-in block fits. See the Blocks page for the architecture and upload.

Until the full guide lands, the Install page gets you running, and Blocks covers the three-tier architecture and how to contribute.
