Quickstart

Install and load the package, then build a sampler from a natural-language description of your model plus the data it should fit.

build_sampler

The top-level entry point. Parses the description, decomposes the model into modular blocks, assigns each to a built-in sampler, runs pre- and post-generation validation, and returns a stateful sampler object.

m <- build_sampler(description, data, validate = TRUE, seed = 1L)
description
Path to a text file, or character vector, containing the natural-language model spec.
data
Named list of observed quantities referenced in the description (e.g. list(y = y, X = X)).
validate
If TRUE (default), runs the two-stage validation pipeline. Set to FALSE to skip the runtime stage.
seed
RNG seed for the sampler.

Stateful interface

Every block, every composite, and the top-level sampler exposes the same four functions. Composition is recursive: calling step on a composite calls step on each constituent in turn.

step

Advance the sampler by one or more iterations, holding all other state fixed. Each call updates the chain in place.

m$step(n_burn = 0, n_keep = 0)
n_burn
Iterations to run without recording the trace (warmup / adaptation).
n_keep
Iterations to run and record into the internal history.

set_current

Inject updated values for the conditioning quantities D (data, fixed predictors, latents owned by other blocks). The block’s own state is preserved; only the inputs change.

m$set_current(name = value, ...)

get_current

Read the block’s current state without advancing the chain. Returns a named list of all sampled parameters at iteration t.

m$get_current()

get_history

Return the recorded trace as a named list. Scalars become length-n_keep vectors; vector parameters become n_keep × dim matrices.

trace <- m$get_history()

readapt_nuts

Re-tune the NUTS step size and mass matrix at any point in the chain. Useful when the target geometry changes mid-run (e.g. after a tempering update).

m$readapt_nuts(n_adapt = 500)

Diagnostics

Runtime validation runs automatically when diagnosis = TRUE is passed to build_sampler. The results are attached to the chain object.

diagnosis

A named list of standard convergence statistics for every parameter: rank-normalized R-hat, bulk and tail ESS, the number of divergent transitions, and the posterior-predictive p-value where applicable.

m$diagnosis

diagnosis_plot

A composite figure: trace plots, marginal densities, autocorrelation, and convergence statistics for each parameter group. Returned as a ggplot object (R) or matplotlib figure (Python).

print(m$diagnosis_plot)

validate

Run pre- or post-generation validation on demand. Returns a structured report of semantic checks (model identifiability, prior support, observation constraints) and runtime checks (sampler diagnostics).

report <- validate(m, stage = "all")

Composition

Composites are blocks that contain other blocks. They orchestrate the order of updates and carry a shared pool of current values.

compose_blocks

Build a composite from a list of constituent blocks. The composite is itself a block — same interface, same stateful guarantees.

outer <- compose_blocks(list(beta_block, sigma_block, hmm_block))

shared_pool

Inspect the shared-state pool of a composite. Useful for debugging cross-block dependencies and confirming that conditioning quantities propagate as expected.

outer$shared_pool()

extending the catalog

Add a new block by providing a target-density function, the four stateful methods, and an AI Skill (a short markdown reference example) that tells the agent when to assign your block. See the block catalog for examples.

register_block(name = "my_block", target = ..., interface = ..., skill = ...)
