# registry/: accepted contributed blocks

This folder contains contributed block bundles that have been reviewed and
accepted. Each subfolder is one block bundle
(`manifest.dcf`, `<block>.hpp`, `skills/`, `test_<block>.cpp`, and optional
`examples/` / `vendor/`).

The **Contributed blocks** tab on the site's Blocks page is built from this folder. A block
is added here only after it passes review. Submissions start in `../submissions/`.
