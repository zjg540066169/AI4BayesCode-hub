# registry/ — accepted contributed blocks

Reviewed, accepted community block bundles. Each subfolder is one block bundle
(`manifest.dcf`, `<block>.hpp`, `skills/`, `test_<block>.cpp`, and optional
`examples/` / `vendor/`).

The **Contributed blocks** page on the site is built from this folder. A block
lands here only after it passes review. Submissions start in `../submissions/`.
