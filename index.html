AI4BayesCode

From natural language to validated, modular, stateful Bayesian samplers.

AI4BayesCode is an extensible, LLM-driven system that turns a natural-language Bayesian model description into a runnable, validated MCMC sampler. A modular design decomposes the model into sampling blocks, each mapped to a built-in component, so complex sampling algorithms aren’t reimplemented from scratch. Validation covers the model specification (before generation) and the sampler code (after). A recursively stateful paradigm composes blocks (even from different contributors) into larger MCMC procedures, usable from R, Python, or C++.

What it is

An LLM-driven system that builds complete MCMC samplers from a model spec.

Rather than asking a language model to write a sampler from scratch, where complex algorithms quietly go wrong, AI4BayesCode decomposes the model into modular blocks and binds each to a built-in sampling component.

From a plain-language description to a runnable sampler.

AI4BayesCode parses your model description, decomposes it into modular blocks, and assigns each block to a built-in sampling component (wrapper · block · kernel). You write the model. The system writes (and validates) the sampler.

Stateful blocks that compose without reinitialising.

Every block exposes the same set_current / step / get_current interface. Embed a BART ensemble or NUTS chain inside a larger MCMC, propagate updated inputs through a shared pool, and continue sampling, with no warm-up reset and no lost adaptation.

Catches errors before you ever read the trace.

Semantic checks at parse time catch mis-specified priors and support mismatches before code is generated. Runtime checks compute R-hat, ESS, divergences, and posterior-predictive p-values automatically, with diagnostics attached to every chain.

Examples

From description to runnable chain.

You write the model in natural language, with priors and likelihood. AI4BayesCode builds the sampler, validates it, compiles it to C++, and ships R and Python bindings. Below are three short prompts and the samplers they produce.

Natural-language prompt

I have n observations of a continuous response y and a design matrix X. Fit a Bayesian linear regression with a horseshoe prior on the regression coefficients and a half-Cauchy prior on the residual scale.

Blocks selected

nuts_block(β, log τ)
half_cauchy_block(σ)

Generated R interface

# pre-generation: model parsed + checked
library(AI4BayesCode)

m <- build_sampler(
  description = readLines("prompt.txt"),
  data        = list(y = y, X = X)
)

# stateful interface: same on every block
m$step(n_burn = 2000)
m$step(n_keep = 4000)
trace <- m$get_history()

# post-generation diagnostics auto-attached
m$diagnosis      # R-hat, ESS, divergences
m$diagnosis_plot # trace + density grid

Natural-language prompt

Spike-and-slab regression with Dirac spike at zero and a Laplace slab. Sample the inclusion indicators γ and the coefficients β jointly via reversible-jump MCMC.

Blocks selected

rjmcmc_block(β, γ)
inverse_gamma_block(σ²)
beta_block(τ²)

Generated R interface

# trans-dimensional sampler from a 4-line description
m <- build_sampler(
  description = "spike-and-slab regression ...",
  data        = list(y = y, X = X),
  validate    = TRUE
)

# model averaging is automatic
m$step(n_burn = 4000)
m$step(n_keep = 4000)

inc <- colMeans(m$get_history()$gamma)
plot(inc, type = "h",
     ylab = "posterior inclusion probability")

Natural-language prompt

Three-state Poisson hidden Markov model. Time series y1:T with state-specific Poisson rates ordered ascending and a sticky transition matrix. Sample the hidden states with forward-filter backward-sample.

Blocks selected

hmm_block(z, FFBS)
dirichlet_gibbs_block(A, π)
gamma_gibbs_block(λ)

Generated R interface

# composite block: HMM nested inside the outer chain
m <- build_sampler(
  description = "3-state Poisson HMM ...",
  data        = list(y = y, K = 3)
)

m$step(n_burn = 1500)
m$step(n_keep = 2000)

# exact forward-backward state marginals available
gamma_smooth <- m$state_marginals()
