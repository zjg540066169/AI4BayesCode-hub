Contributing

An open, extensible system.

AI4BayesCode grows by adding blocks. The block-level extension interface (an AI Skill plus a stateful kernel) is designed so that domain specialists can ship a new sampling block without modifying the system core. We welcome contributions to the block library, new front-end bindings, and new benchmark models.

Add a block

Write the stateful interface, the conditional target, and a one-shot AI Skill that tells the agent when to use it. See extending the catalog.

Add a benchmark

Contribute a natural-language model description, a known-truth DGP, and a reference oracle (long-run MCMC, exact forward-backward, or a hand-coded sampler).

Add a binding

The kernel tier is C++. Front-ends already exist for R and Python; bindings for Julia, Rust, or any FFI-friendly language are welcome contributions.
